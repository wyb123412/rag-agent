# 计算机网络基础

## HTTP 与 HTTPS
HTTP 明文传输，HTTPS 在 HTTP 和 TCP 之间加了 TLS 加密层，保证机密性与完整性。常见状态码：200 成功、404 未找到、500 服务器错误。

## TCP 三次握手与四次挥手
建立连接三次握手（SYN → SYN+ACK → ACK）；断开连接四次挥手。TCP 可靠传输靠序列号、确认应答、重传机制。

## DNS 解析
DNS 把域名解析成 IP 地址，按缓存、本地 hosts、递归查询的顺序查找。

## IP 与端口
IP 定位主机，端口定位进程；常见端口 80(HTTP)、443(HTTPS)、22(SSH)。
